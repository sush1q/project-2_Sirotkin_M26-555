# Primitive DB

Учебная консольная база данных на Python. Позволяет создавать таблицы,
добавлять, читать, изменять и удалять записи используя CLI интерфейс.

## Установка и запуск

Требуются Python 3.12 или новее и uv.
Выполняйте команды из корня проекта:

```bash
uv sync
uv run database
```

Те же действия через Makefile:

```bash
make install
make project
```

После запуска вводите команды в приглашении `Введите команду:`.
`help` показывает справку, `exit` завершает работу.

## Управление таблицами

```text
create_table users name:str age:int is_active:bool
list_tables
info users
```

- `create_table` создаёт таблицу с указанными столбцами.
- `list_tables` выводит список таблиц.
- `info` показывает столбцы, их типы и количество записей.
- `drop_table users` удаляет таблицу и её данные после подтверждения.

Поддерживаются типы `str`, `int` и `bool`. Столбец `ID:int` добавляется
автоматически; при вставке записи значение ID указывать не нужно.

## CRUD-операции

Добавление записей — значения перечисляются в порядке столбцов при создании
таблицы, без ID:

```text
insert into users values ("Pavel", 28, true)
insert into users values ("Anna Smith", 21, false)
```

Чтение всех записей или выборка по условию:

```text
select from users
select from users where age = 28
```

Изменение и удаление записей:

```text
update users set age = 29 where ID = 1
delete from users where ID = 1
```

Команды `update` и `delete` требуют условие `where`. Поддерживается одно
условие равенства, а в `set` — присваивание одному столбцу. Если условию
соответствует несколько записей, операция применяется ко всем этим записям.
Изменять ID нельзя.

Строки заключаются в одинарные или двойные кавычки, целые числа вводятся
без кавычек, логические значения — `true` и `false`. Тип значения должен
соответствовать типу столбца. Ключевые слова команд вводятся в нижнем регистре.

## Декораторы и кэширование

- `handle_db_errors` обрабатывает ошибки валидации, отсутствующих столбцов
  и файлов и выводит понятное сообщение. После ошибки можно продолжить работу.
- `confirm_action` запрашивает подтверждение перед удалением записей
  и таблиц. Ответ `y` или `Y` подтверждает действие; другой ввод отменяет его.
- `log_time` измеряет время выполнения `insert` и `select` с помощью
  `time.monotonic()` и выводит результат с точностью до тысячной секунды.
- `create_cacher` хранит результаты `select` в замыкании. Повтор команды
  с тем же текстом использует сохранённый результат. Кэш очищается после
  успешного создания или удаления таблицы, вставки, изменения или удаления
  записей, а также при запуске нового сеанса.

При попадании в кэш повторно не вызывается `core.select`, поэтому сообщение
о времени этой функции не выводится. Файл таблицы при этом по-прежнему читается.

## Хранение данных

Метаданные сохраняются в `db_meta.json`, записи — в `data/<имя_таблицы>.json`.
Эти файлы создаются относительно текущего рабочего каталога.
Чтобы продолжить работу с той же базой, запускайте приложение из того же каталога.

